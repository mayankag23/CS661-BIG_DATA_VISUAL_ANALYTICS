About This Visualization

This interactive dashboard allows educators and researchers to explore relationships between different aspects of student behavior and performance. The correlation matrix provides an overview of how different variables relate to each other, while the scatter plot shows the detailed relationship between any two selected variables.

Each point in the scatter plot represents an individual student. Hover over points to see detailed information about that student's metrics.
